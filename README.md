# Stormbreaker Minecraft Plugin

Stormbreaker is a Minecraft plugin designed for Spigot servers running version 1.21.11. It introduces a unique trident called Stormbreaker, which can be crafted and used to summon lightning strikes. The plugin preserves the original functionality of the Stormbreaker, including sneak + right-click activation, lightning summoning, 10-second immobilization, and a 60-second cooldown. It also disables the vanilla Mace and Spear where supported.

## Install

1. Download the Stormbreaker plugin JAR file from the releases section.
2. Place the JAR file in the `plugins` folder of your Spigot server.
3. Restart or reload your server to load the plugin.

## Use

1. Craft the Stormbreaker trident using the following recipe:
   - Diamond Block (D) as the center block.
   - Wither Skeleton Skull (R) as the top block.
   - The recipe shape is:
     ```
     D
     D
     R
     ```
2. Hold the Stormbreaker trident in your main hand.
3. Sneak (press the shift key) and right-click to summon a lightning strike at the targeted block.
4. You will be immobilized for 10 seconds after using Stormbreaker.
5. Stormbreaker has a 60-second cooldown before it can be used again.
